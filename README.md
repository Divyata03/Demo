# CampusFind

CampusFind is a campus lost-and-found app for reporting lost and found items, tracking claims, and helping students and staff reconnect with misplaced belongings.

## Development

You need Node.js and npm installed.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Stack

- TanStack Start
- TypeScript
- React
- Vite
- Tailwind CSS
- Supabase
